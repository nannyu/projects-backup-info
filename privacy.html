Privacy policy

Effective November 13, 2026.

Projects Backup is a personal utility. It transfers files selected by its owner from the owner’s computer to the owner’s Google Drive using Google’s API. File contents and metadata are processed only to perform and verify backups.

OAuth credentials are stored locally on the owner’s computer. Backup data is stored in the owner’s Google Drive. This informational website receives no OAuth tokens or backup files and has no analytics or advertising scripts.

The utility does not sell Google user data, share it with advertisers, or use it to train AI models. Data is transferred to Google only for the requested backup. Google API data use adheres to the Google API Services User Data Policy, including Limited Use requirements.

The owner controls retention, can delete backups in Google Drive, and can revoke access through Google Account permissions. GitHub Pages hosting may process standard website request logs under GitHub’s privacy policy.
